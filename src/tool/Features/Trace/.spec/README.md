# Specification: The trace command

## 1. Business Goal

<!-- last written by: spec-author, 2026-10-15 (the --report file, decision 0002) -->

The check reports only the rows that fail. A reader who wants to see where every claim stands, which scenarios carry it and which of its named tests exist, reads each § 9 by hand, greps the companions and the test tree, and gets a picture no one else can reproduce. This Feature removes that failure state: `specht trace` prints every claim of every specification with its § 9 status, the scenarios carrying its tag and the resolution of each test it names, through the same resolver the check uses (`0001-F12` C-3), as lines or as one JSON document, without judging the tree and without writing to it; the one file it writes is the one its caller names with `--report`.

### Assumptions

| ID  | Assumption                                                                                                                                                                                                                                                                                                                                                |
| --- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| A-1 | A test's resolution is one of `resolved`, `unresolved`, `unconfigured` and `skipped`: the first three with the meanings `0001-F12` A-2 and B-007 give them (owner, 2026-10-14; B-004), and `skipped` for a test named in a waived, withdrawn or superseded row, which `0001-F12` B-002 does not resolve (owner, 2026-10-15; decision 0002 call 5; B-019). |
| A-2 | The command has no rule id and is not schema-versioned: it runs the same under every shipped pin (owner, 2026-10-14).                                                                                                                                                                                                                                     |
