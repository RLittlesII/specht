# Decision 0003: deliver on the recorded working defaults

**Date:** 2026-10-28
**Basis:** the request to deliver `0001-F11`, A-1 and the explicit proceed-on-default resolutions in § 11.

## The call

Proceed with `specht rules set <id> <level>`, exact lower-case levels, refusal of every invalid manifest, no success output, and no entry removal. Append missing entries or the missing `rules` object before its closing brace, preserving existing bytes outside the insertion. These are implementation assumptions under OQ-1 and OQ-3 to OQ-7, not new owner rulings. The open questions remain available for reversal.
