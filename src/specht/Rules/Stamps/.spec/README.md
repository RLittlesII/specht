# Specification: Section stamp form

## 1. Business Goal

<!-- last written by: spec-author, 2026-10-11 -->

Each section of a Feature specification carries a stamp that says which role wrote it last and on which date, so a reader knows whose section it is now and how old it is. Nothing holds a stamp to one writer: each amendment appends its own date and note, and sometimes its own role, in front of the last, until the stamp is a change log longer than the heading it sits under and its first entry, the oldest, is the one a reader sees. The check says nothing, because it reads no stamp. This Feature removes that failure state: from the schema version that adds the rule (OQ-2), the check warns, on the stamp's line, wherever a stamp holds more than one date or names more than one role.
