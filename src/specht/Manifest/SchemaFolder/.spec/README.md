# Specification: The schema folder

## 1. Business Goal

<!-- last written by: spec-author, 2026-10-15 -->

The frontmatter schemas are read from, and written to, one place: `<root>/.specht/schema/frontmatter/`, a literal in the engine and in the tool (`0001-F5` A-5, C-9; `0001-F1` C-8; ADR-0011). A consumer whose tree keeps its JSON schemas in one folder, or whose configuration folder should hold configuration alone, cannot tell the tool where its frontmatter schemas are; moving the files loses the check, and the manifest, which names every other place the engine looks (brief § 5), is silent on this one. This Feature removes that failure state: the manifest names the frontmatter schema folder as a root-relative path, the engine and the tool read and write the frontmatter schemas where the manifest says and never where a literal says, and a manifest that names no folder keeps today's, so the default manifest changes no verdict.

### Assumptions

| ID  | Assumption                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |

## 4. Constraints

<!-- last written by: spec-author, 2026-10-15 (C-6 names 0.2.0, decision 0002) -->

| ID  | Constraint                                                                                                                                                                                                                                                           | Rules Out                                                                                                                                                                                                                      |
| --- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| C-1 | The frontmatter schema folder is inside the root: `schemaFolder` is a root-relative path of one or more segments joined by `/`, none of them `.` or `..` (B-010 to B-012; `0001-F7` decision 0004; brief § 9).                                                       | An absolute path; a `..` segment; `\`; a folder shared between repositories by path - the shared schema is an upstream source, `spechtSchema` (`0001-F7` decision 0004); a value expanded from an environment variable or `~`. |
| C-2 | The manifest is read at `<root>/.specht/manifest.json` and `schemaFolder` is read from it; the key never names where the manifest is (`0001-F5` C-6).                                                                                                                | A manifest under the named folder; a key that moves the configuration folder; a second manifest.                                                                                                                               |
| C-3 | The engine and the tool read and write a frontmatter schema at one place, the folder the manifest names; the default folder is the default value of `schemaFolder` and no second literal.                                                                            | A literal frontmatter schema folder in a reader or a writer beside the default value; a fallback read from the default folder when the named folder lacks a file; reading two folders and merging.                             |
| C-4 | The default manifest preserves the baseline behaviour: with no `schemaFolder`, every read and write is where it was (B-002; `0001-F5` C-4, B-016).                                                                                                                   | A changed default folder; a default that differs between the check, `init` and `upgrade`.                                                                                                                                      |
| C-5 | `schemaFolder` and `frontmatterSchemas` compose: the folder carries the path and a value carries the file name, and neither carries the other's part (`0001-F5` B-047, decision 0011).                                                                               | A path in a `frontmatterSchemas` value; a file name in `schemaFolder`; a folder per kind.                                                                                                                                      |
| C-6 | `schemaFolder` is read under schema `0.2.0` and later, and rejected under an older pin (`0001-F7` C-4, C-11, B-102; OQ-2, decision 0002); the pin, not the command line, says whether the key is known.                                                              | A key read whatever the pin; a command-line option that stands in for the key under an older pin.                                                                                                                              |
| C-7 | `schemaFolder` is a consumer setting (`0001-F5` C-13; B-019): no shipped manifest sets it, `upgrade` never adds or rewrites it, and `0001-F4` B-004 excludes it.                                                                                                     | `init` writing it; `upgrade` adding or changing it; counting it among the tool-owned keys (`0001-F4` decision 0001).                                                                                                           |
| C-8 | Every path derived from `schemaFolder` - in a rejection, a diagnostic, a report or an `init` or `upgrade` listing - is relative to the root with `/` separators, and a rejected value is not echoed (B-010; brief § 9; `0001-F1` C-4; `0001-F4` C-4; `0001-F7` C-7). | An absolute value repeated in a rejection; an OS separator in a derived path.                                                                                                                                                  |
