# SPCT0005: Referenced identity is ambiguous

| Property         | Value                            |
| ---------------- | -------------------------------- |
| Message          | The offending binding attributes |
| Default severity | Warning                          |
| Code fix         | Conditional target selection     |

## Finding and reporting conditions

A complete, grammar-valid relationship resolves to multiple targets or to an
ambiguous Feature owner in the supplied catalog. For example, two selected
records with the same applicable Feature and claim identity make
`<implements feature="F1" claim="B-001" />` ambiguous. The resolver orders
candidate records deterministically, but does not choose one as evidence.
Explicit bindings are validated in selected projects regardless of mandatory
authoring scope or generated-code status.

## Configuration and resolution

Correct duplicate consumer records or provide the intended unambiguous owner
identity under the consumer's epic grammar. Suppression does not resolve the
binding. A code fix can offer eligible targets for safely replaceable XML when
the supplied catalog has them; it does not repair the catalog itself. See the
[package guide](../README.md) for selected input configuration.
