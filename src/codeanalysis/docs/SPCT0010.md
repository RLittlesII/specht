# SPCT0010: Duplicate claim declaration

| Property         | Value                                  |
| ---------------- | -------------------------------------- |
| Message          | The claim id and its first declaration |
| Default severity | Warning                                |
| Code fix         | No                                     |

## Finding and reporting conditions

The same claim id is declared by more than one scenario or scenario outline in
the supplied claim files. The first declaration, by path and line, owns the
claim; each later declaration produces a finding that names the first.

## Configuration and resolution

This finding exists only when `codeAnalysis.records.claimSource` is
`"gherkin"`. It is reported on the claim file at the offending line, with
`SpechtRelativePath` and `SpechtLine` properties. Standard Roslyn controls
change its severity or suppress it; neither changes the claim catalogue. There
is no code fix; edit the claim file. See the [package guide](../README.md).
