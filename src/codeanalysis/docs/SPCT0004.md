# SPCT0004: Referenced target is absent

| Property         | Value                            |
| ---------------- | -------------------------------- |
| Message          | The offending binding attributes |
| Default severity | Warning                          |
| Code fix         | Conditional target selection     |

## Finding and reporting conditions

A well-shaped binding has an identity that matches the consumer grammar, but
no matching claim or ADR exists in the complete supplied catalog. For example,
`<implements feature="F1" claim="B-999" />` reports when that selected Feature
has no `B-999`. This differs from unavailable or invalid input, which reports
[SPCT0001](SPCT0001.md). Explicit bindings in selected projects are checked
even outside required-authoring scopes and in generated code.

## Configuration and resolution

Check the selected Feature and ADR records and the identity values. The catalog
comes from the actual consumer inputs; the analyzer does not invent missing
records. Suppression does not create evidence. When the XML can be safely
replaced, the code fix can select an eligible target from the supplied catalog.
See the [package guide](../README.md) for input selection.
