# SPCT0001: Consumer analysis input unavailable

| Property         | Value                                                                                     |
| ---------------- | ----------------------------------------------------------------------------------------- |
| Message          | `Required consumer input is missing, invalid or incompatible with its explicit mappings.` |
| Default severity | Error                                                                                     |
| Code fix         | No                                                                                        |

## Finding and reporting conditions

The current compilation cannot form an available analysis snapshot. The
analyzer reports an input failure when a required file is missing or unreadable,
its relative path or provenance is invalid or duplicated, configuration or
explicit mappings are invalid, a selected Feature is absent, or a supplied
record fails its supplied schema. The diagnostic is attached to the supplied
AdditionalFile when possible; otherwise it has no source location. Its
`SpechtRelativePath` property identifies the affected root-relative input and
`SpechtAnalysisAvailable` is `false`. Binding diagnostics stop when the snapshot
is unavailable. A genuinely absent _referenced target_ in a complete catalog
instead produces [SPCT0004](SPCT0004.md).

## Configuration and resolution

The [package guide](../README.md) describes root selection and AdditionalFiles
metadata. Supply the actual consumer configuration, explicit mappings, selected
Feature and ADR records, and required schemas. For example, an enforcement scope
that selects a Feature absent from the supplied records leaves analysis
unavailable until that Feature is supplied. The analyzer does not fetch an
embedded replacement schema. Standard Roslyn controls can change presentation
but cannot make unavailable inputs valid. There is no code fix; correct the
build inputs or their configuration.
