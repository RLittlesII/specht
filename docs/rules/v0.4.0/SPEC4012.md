# SPEC4012: No claim tag on an Examples block

## Metadata

| Property         | Value        |
| ---------------- | ------------ |
| Rule ID          | SPEC4012     |
| Family           | Feature file |
| Default severity | Error        |
| Schema version   | 0.4.0        |

## Cause

A tag on an `Examples:` or `Scenarios:` block in a claim file is a claim tag. A claim is declared on a scenario, a `Rule:` or the `Feature:`, never on an Examples block, so the tag declares nothing. The diagnostic names the tag at its own line, in the claim file, with the claim id it would declare.

| Condition                             | Message                                            |
| ------------------------------------- | -------------------------------------------------- |
| A claim tag sits on an Examples block | `claim tag on an Examples block declares no claim` |

## Rule description

The rule reads only when the manifest sets `claim.source` to `gherkin`. A claim file is a `.feature` file a `claim.files` entry's `glob` matches outside `exclusions`; a companion `.feature` beside a Markdown specification is not one. A file two entries match is reported once.

A claim tag is `claim.tag` around a text the claim grammar matches, compared under `claim.tagIgnoreCase`. Each claim tag on a block is reported, and each block of an outline is read on its own:

- An ordinary tag, a mistyped claim tag among them, is not reported.
- A `claim.plannedTags` tag on a block marks its rows planned and is not reported.
- The tag records no claim, so the outline keeps only the claim it carries otherwise. An outline with no other claim is also reported by `SPEC4011`.

A claim file the check cannot read is reported by `SPEC4013`, not here.

### Example violation

`@B-005` sits on the Examples block, not on the outline.

```gherkin
Feature: Arithmetic

  Scenario Outline: Adds <a>
    Given <a>

    @B-005
    Examples:
      | a |
      | 1 |
```

```text
.spec/features/arithmetic/add.feature(6): error SPEC4012: claim tag on an Examples block declares no claim [B-005]
```

### Corrected

Move the tag to the outline:

```gherkin
  @B-005
  Scenario Outline: Adds <a>
    Given <a>

    Examples:
      | a |
      | 1 |
```

## How to fix violations

- **The outline states the claim.** Move the tag to the `Scenario Outline:`, or to the `Rule:` that groups it.
- **The rows state different claims.** Split them into outlines, each tagged with its claim.
- **The tag is not a claim.** Rename it so the claim grammar does not read it, or set `SPEC4012` to `off` in the manifest's `rules`.
