# SPEC4007: Every scenario a matrix row names carries its claim

## Metadata

| Property         | Value        |
| ---------------- | ------------ |
| Rule ID          | SPEC4007     |
| Family           | Feature file |
| Default severity | Error        |
| Schema version   | 0.4.0        |

## Cause

With `matrix.scenarioTitles` set to `true`, a § 9 row's Scenario cell names a title that no `Scenario:` or `Scenario Outline:` in the specification's companion has, or a title whose scenarios do not carry the row's claim tag. The diagnostic names the claim at its matrix row, once for each such title.

| Condition                                         | Message                                                                                    |
| ------------------------------------------------- | ------------------------------------------------------------------------------------------ |
| No scenario has the title                         | `§ 9 names scenario '{title}', which no Scenario or Scenario Outline in the companion has` |
| Scenarios have the title and none carries the tag | `§ 9 names scenario '{title}', which does not carry the tag of {claim}`                    |

## Rule description

The matrix columns are read by position from `tables.matrix`: claim, scenario, test, status. A Scenario cell is split on `;` into titles, each trimmed, and each title is compared whole and case-sensitively with the text after `Scenario:` or `Scenario Outline:`; `Example:` and `Scenario Template:` titles are not read. A scenario carries the tags on the lines above it, those above `Feature:` and its `Rule:`, and, for an outline, those above its `Examples:` or `Scenarios:`. The claim tag is `claim.tag` around the row's claim, compared under `claim.tagIgnoreCase`.

Every row is read, whatever its Status. With `matrix` left out, or `scenarioTitles` false, the Scenario cell is prose and the rule reports nothing.

### Example violation

The manifest sets `"matrix": { "scenarioTitles": true }`, and the companion's scenario tagged `@B-001` is titled `An empty order is rejected`.

```markdown
| B-001 | Empty orders are rejected | `RejectsAnEmptyOrder` | Covered |
```

```text
src/orders/.spec/README.md(43): error SPEC4007: § 9 names scenario 'Empty orders are rejected', which no Scenario or Scenario Outline in the companion has [B-001]
```

### Corrected

Name the scenario by its title:

```markdown
| B-001 | An empty order is rejected | `RejectsAnEmptyOrder` | Covered |
```

## How to fix violations

- **No such title.** Copy the title from the companion, or separate several titles with `;`.
- **Untagged scenario.** Tag the scenario with the row's claim, or name the scenario that carries it.
- **Prose in the cell.** Leave `matrix.scenarioTitles` off while Scenario cells describe rather than name.
