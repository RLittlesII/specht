# SPEC4013: Every claim file, set and record can be read

## Metadata

| Property         | Value        |
| ---------------- | ------------ |
| Rule ID          | SPEC4013     |
| Family           | Feature file |
| Default severity | Error        |
| Schema version   | 0.4.0        |

## Cause

The check cannot take claims from part of the claim input the manifest's `claim.files` names. The diagnostic names the place:

| Condition                                                                        | Where                                 | Message                                                                    |
| -------------------------------------------------------------------------------- | ------------------------------------- | -------------------------------------------------------------------------- |
| A claim file declares a `# language:` other than `en`                            | the file, at the header's line        | `claim file cannot be read as English Gherkin, so it declares no claim`    |
| A claim file is not Gherkin the reader takes                                     | the file, with no line                | `claim file cannot be read as English Gherkin, so it declares no claim`    |
| A set's `glob` matches no claim file                                             | the `glob` as written, with no line   | `claim file set matches no claim file`                                     |
| Two sets' globs match one claim file                                             | the file, with no line                | `claim file matches more than one claim file set, so it declares no claim` |
| A Feature-level tag `claim.scopes.featureTag` reads names another Feature        | the file, at the tag's line           | `Feature-level tag names a Feature other than its claim file set's`        |
| A set's `record` names no file, one that cannot be read, or one outside the root | the `record` as written, with no line | `claim file set's Feature document cannot be read under the root`          |
| A set's `record` is an absolute path                                             | `.specht/manifest.json`, with no line | `claim file set's Feature document is an absolute path`                    |

## Rule description

The rule reads only when the manifest sets `claim.source` to `gherkin`. A claim file is a `.feature` file a `claim.files` entry's `glob` matches outside `exclusions`.

A claim file is not Gherkin the reader takes when it has no `Feature:` line, a second one, a table row with a different number of cells, a malformed tag, an unterminated doc string, tags followed by no element, or an `Examples:` with no outline above it. An empty file is one. Such a file declares no claim.

A file two sets match declares no claim under either set. It is reported once, and `SPEC4011` and `SPEC4012` still read it.

A Feature-level tag is read only when `claim.scopes.featureTag` holds exactly one `{feature}`. A tag naming the set's own `feature` is not reported, and the file's claims stay under its set.

A set whose `record` cannot be read is read as a set with no record. An absolute path is never printed: the diagnostic names the manifest instead, and its identifier is the set's `feature`.

### Example violation

```gherkin
# language: de
Funktionalität: Arithmetik
```

```text
.spec/features/arithmetic/add.feature(1): error SPEC4013: claim file cannot be read as English Gherkin, so it declares no claim
```

### Corrected

Write the claim file in English Gherkin:

```gherkin
Feature: Arithmetic

  @B-001
  Scenario: Adds
    Given two numbers
```

## How to fix violations

- **The file is in another language or not valid Gherkin.** Write it in English Gherkin, or exclude it from the set's `glob`.
- **The glob matches nothing.** Correct the `glob`, or remove the set.
- **Two sets match one file.** Narrow one `glob` so each file belongs to one set.
- **A Feature-level tag names another Feature.** Correct the tag, or move the file to that Feature's set.
- **The record cannot be read.** Give `record` a path relative to the root that names the Feature document, or remove it.
