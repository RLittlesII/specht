# SPEC4008: Every live claim is carried by a scenario

## Metadata

| Property         | Value        |
| ---------------- | ------------ |
| Rule ID          | SPEC4008     |
| Family           | Feature file |
| Default severity | Error        |
| Schema version   | 0.4.0        |

## Cause

A claim whose § 3 Status is not the withdrawn or superseded marker has no tag in the specification's companion `.feature`, and its § 9 row's Status is neither the missing nor the waived marker. The diagnostic names the claim at its matrix row, once for each such row.

| Condition                                  | Message                                                                                 |
| ------------------------------------------ | --------------------------------------------------------------------------------------- |
| A live claim's tag is on no companion line | `no companion scenario carries the tag of {claim}, and its § 9 status is not 'Missing'` |

## Rule description

A claim is live unless its § 3 Status is `markers.withdrawn` or `markers.superseded`. Its tag is `claim.tag` around its id, compared under `claim.tagIgnoreCase`, and it is carried when it is on any tag line of a companion: above a `Scenario:`, an outline's `Examples:`, a `Rule:` or the `Feature:` itself. Only the claim's own tag carries it.

The § 9 Status is the fourth column of `tables.matrix`. A row whose Status is `markers.missing` says the scenario is not written yet, and is not reported; a row whose Status is `markers.waived` is judged by `SPEC4005` alone. A claim with no § 9 row is reported by `SPEC4004`, not here.

### Example violation

Claim `B-004` is `Active`, and no companion scenario carries `@B-004`.

```markdown
| B-004 | An empty order is rejected | `RejectsAnEmptyOrder` | Covered |
```

```text
src/orders/.spec/README.md(46): error SPEC4008: no companion scenario carries the tag of B-004, and its § 9 status is not 'Missing' [B-004]
```

### Corrected

Tag the scenario that states the claim:

```gherkin
@B-004
Scenario: An empty order is rejected
```

Or record the row as missing until the scenario exists:

```markdown
| B-004 | An empty order is rejected | Missing | Missing |
```

## How to fix violations

- **The scenario exists.** Add the claim's tag to it.
- **The scenario is not written yet.** Set the row's Status to the missing marker.
- **The claim no longer holds.** Mark it withdrawn or superseded in § 3 and in its row.
