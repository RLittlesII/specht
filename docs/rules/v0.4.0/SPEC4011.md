# SPEC4011: Every scenario in a claim file carries a claim

## Metadata

| Property         | Value        |
| ---------------- | ------------ |
| Rule ID          | SPEC4011     |
| Family           | Feature file |
| Default severity | Warning      |
| Schema version   | 0.4.0        |

## Cause

A `Scenario:`, `Example:`, `Scenario Outline:` or `Scenario Template:` in a claim file carries no claim tag, and neither does the `Rule:` it sits under nor the file's `Feature:`. The diagnostic names the scenario at its keyword line, in the claim file.

| Condition                    | Message                                                                     |
| ---------------------------- | --------------------------------------------------------------------------- |
| A scenario declares no claim | `scenario declares no claim and inherits none from its Rule or its Feature` |

## Rule description

The rule reads only when the manifest sets `claim.source` to `gherkin`. A claim file is a `.feature` file a `claim.files` entry's `glob` matches outside `exclusions`; a companion `.feature` beside a Markdown specification is not one. A file two entries match is reported once.

A claim tag is `claim.tag` around a text the claim grammar matches, compared under `claim.tagIgnoreCase`. A tag on the scenario declares its claim; a tag on its `Rule:` or on the `Feature:` is inherited by every scenario under it. Nothing else carries a claim:

- An ordinary tag, a mistyped claim tag among them, declares nothing.
- A claim tag on an `Examples:` block declares nothing, and `SPEC4012` reports the tag; the outline is reported here unless it carries a claim otherwise.
- A scenario carrying a `claim.plannedTags` tag is reported like any other.
- A claim id in a title or a step is not a claim.

A claim file the check cannot read is reported by `SPEC4013`, not here.

### Example violation

`Subtracts` carries no claim, and neither does `Feature: Arithmetic`.

```gherkin
Feature: Arithmetic

  @B-001
  Scenario: Adds
    Given two numbers

  Scenario: Subtracts
    Given two numbers
```

```text
.spec/features/arithmetic/add.feature(7): warning SPEC4011: scenario declares no claim and inherits none from its Rule or its Feature
```

### Corrected

Tag the scenario with the claim it states:

```gherkin
  @B-002
  Scenario: Subtracts
    Given two numbers
```

## How to fix violations

- **The scenario states a claim.** Add the claim's tag to it, or to the `Rule:` that groups its scenarios.
- **Every scenario states one claim.** Tag the `Feature:`.
- **The scenario states no claim.** Remove it, or set `SPEC4011` to `off` in the manifest's `rules`.
