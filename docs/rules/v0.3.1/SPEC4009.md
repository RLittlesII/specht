# SPEC4009: Every test a matrix row names exists

## Metadata

| Property         | Value    |
| ---------------- | -------- |
| Rule ID          | SPEC4009 |
| Family           | Claims   |
| Default severity | Error    |
| Schema version   | 0.3.1    |

## Cause

A § 9 row's Test cell names a test that no file the manifest's `tests.files` selects holds, or holds no inline code at all. The diagnostic names the claim at its matrix row, once for each unresolved name.

| Condition                                | Message                                                      |
| ---------------------------------------- | ------------------------------------------------------------ |
| A test name resolves in no declared file | `§ 9 names test '{name}', which no declared test file holds` |
| The Test cell holds no inline code       | `§ 9 Test cell names no test in inline code`                 |

## Rule description

The matrix columns are read by position from `tables.matrix`: claim, scenario, test, status. A Test cell's test names are its inline-code spans, each split on `,` and `;`; prose around them is not a name. A dotted name `A.B` resolves when one declared file holds `B` in a declared form and `A` as a whole word. With no `tests.declarations` a name's form is the name as a whole word; with forms such as `"let {test} "`, only a declaration in one of them counts. Files under `exclusions` are not read.

A row is skipped when its Status is the waived, withdrawn or superseded marker, or its Test cell is the missing marker. With no `tests` key the rule reports nothing. Resolution is text only: no build, no test run.

### Example violation

The manifest declares `"tests": { "files": ["test/**/*.cs"] }`, and no file under `test/` holds `RejectsAnEmptyOrder`.

```markdown
| B-001 | An empty order is rejected | `RejectsAnEmptyOrder` | Covered |
```

```text
src/orders/.spec/README.md(43): error SPEC4009: § 9 names test 'RejectsAnEmptyOrder', which no declared test file holds [B-001]
```

### Corrected

Name the test as it is declared, or record the row as missing until it exists:

```markdown
| B-001 | An empty order is rejected | Missing | Missing |
```

## How to fix violations

- **Unresolved name.** Correct the name, qualify it with its class as `Class.Method`, or add the test.
- **No inline code.** Put each test name in backticks, or write the missing marker when no test exists.
- **A declared test outside the globs.** Widen `tests.files`, or move the file out of an excluded folder.
