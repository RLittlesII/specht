# Decision 0002: three rows against an empty tool, and the tool process's memory

**Date:** 2026-10-09
**Decided by:** the repository owner, answering OQ-1 and OQ-2 (2026-10-09);
the packing split in the last bullet of "The call" is the orchestrator's
default, not the owner's

## The call

- **Three rows**, each from process start to exit and each a ratio of the
  first (B-009, C-1):
  - **Baseline:** a minimal local tool, generated by the benchmark code, that
    does nothing and exits `0`, installed exactly as `specht` is (B-007, C-8).
  - **Host:** `specht --help`, which composes the host and runs no check
    (B-008, A-3).
  - **Check:** one check of the one-specification generated tree, the row
    decision 0001 defined (B-002).
- **The tool process's memory is measured** (OQ-1, reversing its default):
  the peak memory of the measured tool's own process, apart from the `dotnet`
  command that launches it and the benchmark process (B-006, C-7).
- **Packing the baseline tool** is the benchmark code's, inside its own
  temporary directory; the benchmark target packs only `specht` (C-8;
  `0109-F1` B-013, A-3). Orchestrator default, 2026-10-09.

## Why

- A tool that does nothing, launched through a local tool manifest, is the
  floor of the launch path every call site takes, so the ratios separate what
  launching a tool costs from what `specht`'s host and engine add.
- `--help` is the only invocation that composes the host and reads no tree:
  the tool has no `--version`, and `--explain` is not built.
- The check stays the main row, because it is the command a call site runs
  (decision 0001).
- The owner asked for memory on every benchmark, and the library's allocation
  column here is the benchmark process's, not the tool's.

## Rejected

**The bare .NET host, or `dotnet --version`, as the baseline.** Both measure
the `dotnet` muxer, not the tool-launch path a consumer's hook takes. Cost of
rejecting: the benchmark generates, packs and installs a tool of its own.

**Adding `--version`, or another no-op, to `specht` for the host row.** A
product change outside this epic (§ 5 row 8). Cost of rejecting: the host row
prints usage, a little more than composing the host.

**The tool process's memory left unmeasured** (OQ-1's default). Cost of
rejecting: reading it outside the library's memory diagnoser, a mechanism the
`implementer` owns in § 7.

**The build target packing the baseline tool.** It would give the package two
owners. Cost of rejecting: the benchmark code packs a package of its own.

## Affects

- `0109-F4` B-006 to B-009; C-1, C-7, C-8; A-3; § 5 rows 4, 5 and 8.
- `0109-F1` B-013 and A-3, which keep packing to the `specht` tool package.

## Reversal

None.
